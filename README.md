# Check-Unused-HTML-Classes-Extension
This extension will allow you to check all the classes in your HTML (also supporting IDs), where they are located and above all whether they are used or not (many times we declare a class or IDs and perhaps do not give them a specific utility, with this extension you can check what we are using and what we are not using)

## Installation

### From VSIX file
1. Open VS Code
2. Press `Ctrl + Shift + X` to open the Extensions panel
3. Click the three dots `···` in the top right corner of the panel
4. Click `Install from VSIX...`
5. Select the `unused-html-classes-0.0.1.vsix` file
6. Restart VS Code when prompted

## How to use

1. Open an HTML file
2. Open the command palette with `Ctrl + Shift + P`
3. Search for `Check Unused HTML Classes` and press Enter
4. Check the "HTML Class Checker" panel for the results
